# Pinned rendering fonts

Noto Sans and Noto Serif regular/bold/italic/bold-italic from `googlefonts/noto-fonts` (`hinted/ttf/NotoSans` and `hinted/ttf/NotoSerif`). Distributed under SIL Open Font License 1.1; see `LICENSE`.

The font files are embedded into server PDFs and the WPF application. Updating these assets changes rendering and requires new golden-output and printer evidence. Bengali/other complex-script shaping is not yet validated; unsupported glyphs are rejected rather than silently replaced.
